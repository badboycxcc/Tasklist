「弱点」是怎么判定的
  • 系统已停止支持(EOL)：识别出 Windows XP / 2003 / Vista / 7 / 2008 / 2008 R2 / 8 / 2012 / 2012 R2 / 10，以及 Ubuntu / CentOS / Debian / RHEL / ESXi 等版本，按官方支持终止日期判定是否已 EOL，并给出 EOL 日期。
  • 弱口令：从 fscan 的爆破结果里提取 user:pass；匿名账号（anonymous/guest）单独标为可直接登录。
  • 未授权访问：结果里出现 unauthorized / no auth / 未授权 字样（Redis、ES、Docker API、K8s、WebLogic 等）。
  • 已知漏洞：MS17-010、CVE-xxxx-xxxx、SMBGhost、BlueKeep、poc-yaml-* 等命中项。
  • 高危端口：445/139/135/3389/5985、1433/3306/5432/1521/27017/6379/9200/11211、2375、5900、23、2049 等，附可利用提示。
  • 组件版本过旧：Tomcat / Apache httpd / nginx / OpenSSH / OpenSSL / PHP / IIS / ProFTPD / vsftpd 等版本比对。
  • 风险分：0–100 累加（EOL 40 / 弱口令 40 / 漏洞 40 / 未授权 25 / 高危端口 8 / 组件 6–25），≥70 严重、≥50 高、≥25 中。
建议的 fscan 命令 
fscan -h 192.168.1.0/24 -p 1-65535 -o result.txt   # 全端口 + 落文件
fscan -h 192.168.1.0/24 -m smb,netbios -o s.txt    # 只探 NetBIOS/SMB 拿系统版本
# 把 result.txt 内容整体粘到上面即可（banner、进度条、[*] 状态行会自动忽略）

How weaknesses are scored
  • End-of-life OS: Windows XP/2003/Vista/7/2008/2008 R2/8/2012/2012 R2/10, plus Ubuntu/CentOS/Debian/RHEL/ESXi versions — compared against official support end dates.
  • Weak credentials: user:pass extracted from fscan brute-force hits; anonymous accounts are flagged separately.
  • Unauthenticated access: lines containing unauthorized / no auth (Redis, ES, Docker API, K8s, WebLogic…).
  • Known vulnerabilities: MS17-010, CVE-xxxx-xxxx, SMBGhost, BlueKeep, poc-yaml-*.
  • High-risk ports: 445/139/135/3389/5985, 1433/3306/5432/1521/27017/6379/9200/11211, 2375, 5900, 23, 2049 and more.
  • Outdated components: Tomcat / httpd / nginx / OpenSSH / OpenSSL / PHP / IIS / ProFTPD / vsftpd.
  • Risk score 0–100 (EOL 40 / weak creds 40 / vuln 40 / unauth 25 / risky port 8 / component 6–25); ≥70 critical, ≥50 high, ≥25 medium.
